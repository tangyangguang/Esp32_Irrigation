# 文档

本目录是 12V DC 智能浇水控制器当前唯一有效的产品与软件文档，按下列顺序阅读：

1. [01-产品与硬件边界](01-产品与硬件边界.md)：产品定位、硬件接口、固定参数和安全不变量。
2. [02-业务规则与安全](02-业务规则与安全.md)：水路、计划、手动浇水、自动调度、流量保护、校准、记录和事件。
3. [03-软件设计原则](03-软件设计原则.md)：模块职责、执行模型、数据存储、Web 设计和验证范围。
4. [04-设备维护操作手册](04-设备维护操作手册.md)：本机构建、串口整片烧录、Web OTA 与串口监视的操作步骤。

硬件事实以 `../pcb_irrigation/` 下 2026-07-11 的 BOM 和网表为准；实际实现、构建命令和当前验证基线见 [`../firmware/README.md`](../firmware/README.md)。文档只维护当前有效内容，历史过程见 Git 提交记录。
