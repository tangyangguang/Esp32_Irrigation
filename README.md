# ESP32 Irrigation

六路 12V DC 电磁阀互斥、可选外部泵、流量保护、RTC 自动计划、手动浇水与本地 Web。

- 产品、硬件及安全：[当前方案](docs/当前方案/README.md)。
- 实现、构建、验证及任务收尾状态：[固件说明](firmware/README.md)。
- 通用能力：[Esp32Base](../../foundation/Esp32Base/README.md)。

本地核心重构已完成约定的源码与本机验证：主目标使用 LOCAL Profile；浇水结果与必要操作历史按字节预算分段滚动，当前异常只在 RAM 确认。首页以每日实际浇水时长为主，手动和水路维护低频展示。文件日志保持原实现。

本轮核心、基础库、存储集成和最终固件构建通过。页面以 b831ee3 的原有组件和交互为基准恢复，只适配当前信息结构与业务逻辑；最终固件已串口烧录实验核心板，完成启动、设备静态资源、浏览器页面及手动启动/停止记录验证。当前本地核心与页面恢复任务已收尾，真实水路计量、长期运行及物理断电恢复不在已完成的实机验证范围内。MQTT、IoT 平台和小程序适配属于下一轮独立任务；保留的旧平台适配源码不参与当前目标编译，也不代表与当前核心已兼容。
